# main-praject

Dream Career Explorer - A Flask web application for career exploration, quizzes, and educational pathways.

## Setup Instructions

1. **Create Virtual Environment:**
   ```bash
   uv venv
   # or: python -m venv .venv
   ```

2. **Activate Virtual Environment:**
   - Windows PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
   - Linux/macOS:
     ```bash
     source .venv/bin/activate
     ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run Application:**
   ```bash
   python run.py
   # or: .\.venv\Scripts\python run.py
   ```
